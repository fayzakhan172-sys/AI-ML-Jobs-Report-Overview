📊 AI/ML Jobs Report - Power BI Dashboard

📌 Project Overview

The AI/ML Jobs Dashboard provides an analysis of job opportunities in the Artificial Intelligence and Machine Learning industry.

This Power BI dashboard helps analyze job roles, salaries, experience levels, employment types, company locations, and remote work opportunities.

🎯 Key Insights

- Total AI/ML job opportunities
- Average and highest salaries
- Most in-demand AI/ML job roles
- Salary comparison by experience level
- Job distribution by location
- Remote vs. on-site job opportunities
- Employment type analysis
- AI/ML hiring trends

🛠 Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

📁 Project File

`Power bi Project July.pbix`

Download the PBIX file from this repository and open it using Microsoft Power BI Desktop to explore the interactive dashboard.

📊 Dashboard Features

The dashboard contains interactive charts, KPIs, filters, and slicers that make it easier to understand AI/ML job market trends.

🚀 How to Use

1. Download the `.pbix` file from this repository.
2. Open Microsoft Power BI Desktop.
3. Open `Power bi Project July.pbix`.
4. Use the available filters and slicers to explore the dashboard.
